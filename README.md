# Library-Treasure-Hunt-System

學生版位於 `main`，老師體驗版位於 `demo/teachers`。

學生版保留班級驗證、兩位不同的五位數學號、最多五字隊名，以及每本書重新刷借書證的流程。

## 效能與更新

- 刷證、刷書與排行榜共用最多 10 秒的伺服器快取，減少重複讀取試算表。
- 快取包含班級欄位；同一張借書證在不同班級的紀錄與排名分開計算。
- 成功刷書只寫入一整列，寫入完成後更新快取；重複檢查與寫入有鎖保護。
- 註冊或增刪書單會清除快取。快取遺失、過期或過大時重新讀取試算表。
- 手動修改試算表最遲於快取滿 10 秒後的下一次請求反映。
- 排行榜每 2 秒嘗試更新；前一個請求未完成時不重複送出。提示文字與計時器共用同一設定。
- 既有工作表查詢不再反覆設定整欄格式，僅在初始化或新增資料時處理所需格式。

## 驗證

執行 `node tests/student-scan.cjs` 與 `node tests/student-performance.cjs`。
這些測試使用模擬環境，涵蓋刷證流程、班級隔離、快取失效及更新間隔；實際線上速度需部署後量測。

## 同步

推送 `main` 後，在學生版 Apps Script 選 `main` 拉取，並將學生版部署更新至新版本。
排行榜網址仍需帶班級，例如 `?page=leaderboard&class=603`。
